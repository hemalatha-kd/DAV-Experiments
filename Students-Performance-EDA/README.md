# Student Exam Scores - EDA

## About the Project

This project performs Exploratory Data Analysis (EDA) on a student exam scores dataset using Python.

The dataset contains information about students such as:

* Hours studied
* Sleep hours
* Attendance percentage
* Previous scores
* Exam score

## Tools Used

* Python
* Pandas
* NumPy

## EDA Operations

The program performs:

* Loading CSV dataset
* Viewing first and last rows
* Checking dataset shape and columns
* Checking data types and information
* Statistical analysis
* Finding unique values
* Checking missing values
* Finding and removing duplicates
* Selecting rows and columns
* Conditional filtering
* Sorting data
* Renaming columns
* Creating new columns
* Grouping data
* Concatenating data
* Merging data
* Saving the final dataset

## Files

* `eda_students.py` - Python program for EDA
* `student_exam_scores.csv` - Dataset
* `students_eda_result.csv` - Final output dataset

## How to Run

Install the required libraries:

```bash
pip install pandas numpy
```

Run the program:

```bash
python eda_students.py
```
